## 🚀 كيفية الاستخدام

### الوصول للواجهة الجديدة:
1. الانتقال إلى **الصلاحيات** → **الأدوار**
2. اختيار أي دور من القائمة
3. الضغط على أيقونة **الدرع الأخضر** (🛡️)
4. سيتم فتح الواجهة الحديثة لإدارة الصلاحيات

### خطوات التعيين:
1. **البحث** (اختياري):
   - استخدم شريط البحث للعثور على صلاحية معينة
   - البحث يعمل في الاسم العربي/الإنجليزي/المفتاح

2. **التحديد**:
   - تبديل صلاحية واحدة: استخدم Switch بجانب الصلاحية
   - تحديد كل التصنيف: استخدم Switch في رأس التصنيف
   - التوسيع/الطي: اضغط على بطاقة التصنيف

3. **الحفظ**:
   - سيظهر زر "حفظ التغييرات" تلقائياً
   - اضغط الزر لحفظ جميع التغييرات دفعة واحدة
   - ستظهر رسالة تأكيد عند النجاح

## 🎯 مثال عملي: دور "محاسب"

### السيناريو:
تريد إنشاء دور "ACCOUNTANT" يمتلك صلاحيات محدودة للمعاملات المالية والتقارير فقط.

### الخطوات:
1. ✅ افتح دور ACCOUNTANT
2. ✅ في تصنيف "المالية" 💰:
   - فعّل: `VIEW_SETTLEMENTS` (عرض التسويات)
   - فعّل: `VIEW_PROVIDER_ACCOUNTS` (عرض حسابات المقدمين)
3. ✅ في تصنيف "التقارير" 📊:
   - فعّل: `VIEW_REPORTS` (عرض التقارير)
4. ✅ اترك باقي التصنيفات بدون تفعيل
5. ✅ اضغط "حفظ التغييرات"

### النتيجة:
- سيمتلك المحاسب **3 صلاحيات فقط**
- الإحصائيات ستعرض: `3/48` (حوالي 6%)
- عند دخول المحاسب للنظام:
  - ✅ سيرى قوائم التسويات والحسابات والتقارير
  - ❌ لن يرى قوائم الأعضاء، المطالبات، الباقات، إلخ

## 🐛 المشاكل المحتملة وحلولها

### المشكلة 1: "لا تظهر الصلاحيات"
**السبب المحتمل**: 
- Backend لا يرجع الصلاحيات في response

**الحل**:
```javascript
// التحقق من structure الـ response
console.log('Backend response:', response.data);

// يجب أن يكون:
{
  data: {
    permissions: [
      { id: 1, name: "VIEW_DASHBOARD", ... },
      ...
    ]
  }
}
```

### المشكلة 2: "التصنيفات فارغة"
**السبب المحتمل**:
- عدم تطابق مفاتيح الصلاحيات بين Backend وConfig

**الحل**:
```javascript
// في permission-groups.config.js
// تأكد أن المفاتيح تطابق Backend
permissions: [
  { 
    key: 'VIEW_DASHBOARD',  // يجب أن يطابق permission.name من Backend
    ...
  }
]
```

### المشكلة 3: "الحفظ لا يعمل"
**السبب المحتمل**:
- API endpoint غير صحيح

**الحل**:
```javascript
// في rolesService.js
assignPermissions: (roleId, permissionIds) => {
  return api.put(`/roles/${roleId}/permissions`, { permissionIds });
}
```

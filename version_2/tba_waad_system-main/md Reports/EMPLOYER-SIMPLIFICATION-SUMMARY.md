## 🔢 نظام الأكواد التلقائية

### المواصفات:
- **التنسيق:** `EMP-XX` (رقمين بأصفار أمامية)
- **أمثلة:** EMP-01, EMP-02, ..., EMP-15
- **الحد الأقصى المتوقع:** 15 شريك
- **قابل للتوسع:** ينمو تلقائياً إلى EMP-100 وما بعده عند الحاجة

### آلية التوليد:
1. البحث عن أكبر رقم موجود (مثلاً: EMP-05)
2. الزيادة بمقدار 1 (يصبح: 06)
3. التنسيق برقمين (EMP-06)
4. في حالة عدم وجود أكواد: البدء من EMP-01

### الكود في الباك إند:
```java
private static final String EMPLOYER_CODE_PREFIX = "EMP-";
private static final int EMPLOYER_CODE_LENGTH = 2; // EMP-01, EMP-02
```

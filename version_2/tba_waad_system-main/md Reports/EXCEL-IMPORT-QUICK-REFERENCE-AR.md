# 📋 دليل الاستيراد من Excel - مرجع سريع

## 🎯 نظرة عامة

نظام الاستيراد الجديد يعتمد على **قوالب مُنشأة من النظام فقط**  
✅ تنزيل القالب → ملؤه → رفعه  
❌ لا يُقبل أي ملف Excel خارجي

---

## 📥 خطوات الاستيراد (3 خطوات بسيطة)

### الخطوة 1️⃣: تنزيل القالب
1. اذهب إلى الصفحة المطلوبة (الأعضاء / مقدمي الخدمة / الخدمات الطبية)
2. اضغط على زر **"استيراد من Excel"**
3. اضغط على **"تنزيل قالب Excel"**
4. احفظ الملف على جهازك

### الخطوة 2️⃣: ملء البيانات
1. افتح الملف المُنزّل في Microsoft Excel
2. **لا تعدّل أسماء الأعمدة** (الصف الأول)
3. ابدأ بملء البيانات من **الصف الثالث**
4. اتبع التعليمات التالية:

#### ملاحظات مهمة:
- **الأعمدة الصفراء** = إجبارية (يجب ملؤها)
- **الأعمدة الرمادية** = اختيارية
- **الصف الثاني** = أمثلة (يمكن حذفه)
- **القوائم المنسدلة** = اختر من القائمة فقط
- **ورقة البحث** = استخدم الأسماء المطابقة تماماً

### الخطوة 3️⃣: رفع الملف
1. احفظ الملف بعد الانتهاء من ملئه
2. ارجع إلى النظام
3. اضغط على زر **"استيراد من Excel"**
4. اختر الملف المُعبّأ
5. انتظر النتيجة

## 📊 الأعمدة حسب النموذج

### 👤 الأعضاء (Members)

#### الأعمدة الإجبارية ⭐
| العمود | مثال | ملاحظات |
|--------|------|---------|
| **الاسم الكامل** | أحمد محمد علي | الاسم بالعربية |
| **جهة العمل** | شركة النفط الليبية | يجب أن يطابق الاسم في ورقة "جهات العمل" |
| **تاريخ الميلاد** | 1990-01-15 | صيغة: سنة-شهر-يوم |
| **الجنس** | MALE أو ذكر | استخدم القائمة المنسدلة |

#### الأعمدة الاختيارية
- الاسم بالإنجليزية
- الرقم الوطني
- رقم الهاتف
- البريد الإلكتروني
- رقم الوثيقة
- الجنسية
- الرقم الوظيفي

#### ⚠️ أعمدة محظورة (سيتم تجاهلها)
- ❌ **رقم البطاقة** - يتم توليده تلقائياً
- ❌ **الباركود** - يتم توليده تلقائياً
- ❌ **ID** - يتم توليده تلقائياً

---

### 🏥 مقدمي الخدمة (Providers)

#### الأعمدة الإجبارية ⭐
| العمود | مثال | ملاحظات |
|--------|------|---------|
| **اسم مقدم الخدمة** | مستشفى السلام | الاسم بالعربية |
| **نوع المقدم** | HOSPITAL أو مستشفى | استخدم القائمة المنسدلة |
| **المدينة** | طرابلس | اسم المدينة |

#### الأعمدة الاختيارية
- الاسم بالإنجليزية
- رقم الهاتف
- البريد الإلكتروني
- العنوان

#### أنواع مقدمي الخدمة الصالحة:
- `HOSPITAL` - مستشفى
- `CLINIC` - عيادة
- `LAB` - مختبر
- `PHARMACY` - صيدلية
- `RADIOLOGY` - أشعة

#### ⚠️ أعمدة محظورة
- ❌ **رقم الترخيص** - يتم توليده تلقائياً

## ✅ نصائح للنجاح

### 1. استخدم القوائم المنسدلة
```
✅ اختر من القائمة المنسدلة
❌ لا تكتب يدوياً
```

### 2. طابق الأسماء من ورقة البحث
```
✅ انسخ الاسم من ورقة "جهات العمل"
❌ لا تكتب الاسم يدوياً (قد يحدث خطأ)
```

### 3. استخدم الصيغ الصحيحة
```
✅ التاريخ: 1990-01-15 (سنة-شهر-يوم)
✅ الجنس: MALE أو FEMALE أو ذكر أو أنثى
❌ التاريخ: 15/01/1990 (خطأ)
```

### 4. ابدأ بملف صغير
```
✅ جرّب أولاً مع 5-10 صفوف
✅ تأكد من النتيجة
✅ ثم ارفع الملف الكامل
```

### 5. احتفظ بنسخة احتياطية
```
✅ احفظ نسخة من بياناتك الأصلية
✅ في حالة الحاجة للتصحيح
```

## 📖 فهم النتائج

### نتيجة ناجحة ✅
```
تم الاستيراد بنجاح!
تم إنشاء 45 سجل
تم رفض 5 سجل
```

**معنى الأرقام:**
- **تم الإنشاء** = عدد السجلات الناجحة
- **تم الرفض** = عدد الصفوف التي بها أخطاء
- **فشل** = عدد الصفوف التي حدث بها خطأ غير متوقع

### عرض الأخطاء
اضغط على **"عرض الأخطاء"** لرؤية:
- رقم الصف
- نوع الخطأ
- الوصف
- القيمة الخاطئة

---

## ❌ الأخطاء الشائعة وحلولها

### خطأ: "جهة العمل غير موجودة"
```
❌ المشكلة: كتبت "شركة النفط" يدوياً
✅ الحل: افتح ورقة "جهات العمل" وانسخ الاسم المطابق تماماً
```

### خطأ: "قيمة الجنس غير صحيحة"
```
❌ المشكلة: كتبت "M" أو "رجل"
✅ الحل: استخدم القائمة المنسدلة واختر MALE أو ذكر
```

### خطأ: "تاريخ الميلاد مطلوب"
```
❌ المشكلة: الخلية فارغة
✅ الحل: أدخل التاريخ بالصيغة 1990-01-15
```

### خطأ: "عمود الاسم الكامل مفقود"
```
❌ المشكلة: عدّلت أسماء الأعمدة
✅ الحل: نزّل قالب جديد ولا تعدّل الصف الأول
```

### خطأ: "نوع الملف غير صحيح"
```
❌ المشكلة: رفعت ملف PDF أو Word
✅ الحل: ارفع ملف Excel فقط (.xlsx أو .xls)
```

## 🔍 الأوراق في القالب

### ورقة "Data" (البيانات)
- هذه الورقة لملء البيانات
- الصف 1 = أسماء الأعمدة (لا تعدّل)
- الصف 2 = أمثلة (يمكن حذفه)
- الصف 3+ = بياناتك

### ورقة "Employers" (جهات العمل)
- قائمة بجميع جهات العمل الصالحة
- استخدم الأسماء من هذه الورقة بالضبط
- انسخ والصق (لا تكتب يدوياً)

### ورقة "Metadata" (البيانات الوصفية)
- مخفية (لا تظهر)
- تحتوي على معلومات النظام
- لا تحتاج للتعديل

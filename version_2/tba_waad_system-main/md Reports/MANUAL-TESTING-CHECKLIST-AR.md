## ✅ TEST 1: إنشاء منتفع رئيسي (Member)

### الخطوات:
1. سجل دخول كـ Super Admin
2. اذهب إلى: **المنتفعين > إضافة منتفع جديد**
3. أدخل البيانات التالية **فقط**:
   ```
   الاسم الكامل: علي حسن أحمد اختبار
   صاحب العمل: [اختر أي صاحب عمل]
   الوثيقة: [اختر أي وثيقة]
   الحالة: نشط
   ```
4. **اترك جميع الحقول الأخرى فارغة**:
   - ❌ تاريخ الميلاد
   - ❌ الجنس
   - ❌ الرقم الوطني
   - ❌ رقم البطاقة
   - ❌ البريد الإلكتروني
   - ❌ الهاتف
5. اضغط **حفظ**

### التحقق:
- [ ] ✅ تم الحفظ بدون خطأ 400
- [ ] ✅ تم توليد باركود قصير (مثال: `WAAD-M-000001`)
- [ ] ✅ يظهر الباركود في صفحة العرض
- [ ] ✅ يظهر رمز QR
- [ ] ❌ لم يتم توليد رقم بطاقة تلقائيًا (الحقل فارغ)

### النتيجة:
- [ ] **PASS** - كل الشروط تحققت
- [ ] **FAIL** - فشل في: ___________________

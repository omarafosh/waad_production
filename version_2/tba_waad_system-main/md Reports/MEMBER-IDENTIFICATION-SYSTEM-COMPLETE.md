# ✅ Member Identification System - تنفيذ كامل واحترافي

## 📋 نظرة عامة

تم تنفيذ نظام موحد واحترافي لتعريف المنتفع (Member Identification) مع الالتزام الصارم بالمواصفات المطلوبة.

---

## 🎯 الحقول الأساسية المنفذة

### ✅ 1. fullName
- **النوع**: `String` (NOT NULL)
- **الوصف**: حقل واحد فقط يقبل الاسم العربي أو الإنجليزي
- **إلزامي**: نعم
- **ملاحظات**: لا يوجد أي حقل عربي/إنجليزي منفصل

### ✅ 2. nationalNumber
- **النوع**: `String` (NULLABLE)
- **الوصف**: الرقم الوطني - البديل الرسمي لما كان يسمى سابقاً "الرقم المدني"
- **إلزامي**: لا (OPTIONAL)
- **ملاحظات**: 
  - لا يُستخدم للبحث الإجباري
  - لا يوجد أي تحقق صارم عليه
  - `civilId` تم الاحتفاظ به للتوافق العكسي فقط (deprecated)

### ✅ 3. cardNumber
- **النوع**: `String` (NULLABLE, UNIQUE when not null)
- **الوصف**: رقم بطاقة العضو
- **إلزامي**: لا (OPTIONAL)
- **ملاحظات**:
  - يمكن إدخاله يدوياً عند إضافة أو تعديل المنتفع
  - فريد إن وُجد (unique when not null)
  - يظهر في:
    - ✅ صفحة إضافة المنتفع
    - ✅ صفحة تعديل المنتفع
    - ✅ قائمة الأعضاء (Members List)
    - ✅ صفحة التحقق من الأهلية

### ✅ 4. barcode (QR Code)
- **النوع**: `String` (NOT NULL, UNIQUE)
- **الوصف**: معرف فريد يتولد تلقائياً (UUID)
- **إلزامي**: نعم (OBLIGATORY)
- **ملاحظات**:
  - يتولد تلقائياً عند إنشاء المنتفع (`@PrePersist`)
  - لا يظهر في نموذج إضافة أو تعديل المنتفع
  - يُستخدم فقط للبحث ولطباعة QR
  - لا يمكن للمستخدم إدخاله أو تعديله
  - الصيغة: UUID (مثال: `a1b2c3d4-e5f6-7890-abcd-ef1234567890`)

        Optional<Member> found = memberRepository.findByCardNumber(memberNumber.trim());
        // ...
    }

        // ✅ NEW: Use findByBarcode
        Optional<Member> found = memberRepository.findByBarcode(barcode.trim());

        }

        // ...
    }
}

## 🗄️ Database Migration

**الملف**: `backend/src/main/resources/db/migration/V111__member_identification_system.sql`

### التغييرات:

```sql
-- 1. Add nationalNumber column (NULLABLE)
ALTER TABLE members
ADD COLUMN IF NOT EXISTS national_number VARCHAR(50);

-- 2. Rename qr_code_value to barcode
ALTER TABLE members RENAME COLUMN qr_code_value TO barcode;

-- 3. Generate UUIDs for existing records
UPDATE members
SET barcode = gen_random_uuid()::text
WHERE barcode IS NULL OR barcode = '';

-- 4. Make barcode NOT NULL and UNIQUE
ALTER TABLE members ALTER COLUMN barcode SET NOT NULL;
ALTER TABLE members ADD CONSTRAINT uk_member_barcode UNIQUE (barcode);

-- 5. Make cardNumber NULLABLE
ALTER TABLE members ALTER COLUMN card_number DROP NOT NULL;

-- 6. Create partial unique index (unique only when not null)
CREATE UNIQUE INDEX uk_member_card_number_partial 
ON members (card_number) 
WHERE card_number IS NOT NULL;

-- 7. Create index on nationalNumber
CREATE INDEX IF NOT EXISTS idx_members_national_number 
ON members (national_number)
WHERE national_number IS NOT NULL;
```

## 🔍 Search API Contract

### Endpoint:
```
GET /api/members/search
```

### Parameters (at least one required):
- `cardNumber` - رقم بطاقة العضو (exact match)
- `barcode` - الباركود (exact match)
- `name` - الاسم (partial match, case-insensitive)

### Search Priority:
1. **cardNumber** (exact)
2. **barcode** (exact)
3. **name** (LIKE, ignore case)

### Rules:
- ✅ إذا لم يُرسل أي parameter → 400 Bad Request
- ✅ إذا لا توجد نتائج → 200 OK + `[]`
- ✅ لا ترجع 500 أبداً

### Example Requests:

```bash
# Search by cardNumber
GET /api/members/search?cardNumber=CARD-12345

# Search by barcode (QR)
GET /api/members/search?barcode=a1b2c3d4-e5f6-7890-abcd-ef1234567890

# Search by name
GET /api/members/search?name=أحمد
```

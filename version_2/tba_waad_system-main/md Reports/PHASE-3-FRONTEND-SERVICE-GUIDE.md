## 🎯 Overview

This service provides **complete field normalization** between Frontend and Backend for the Employer domain, ensuring seamless integration with Backend Phase 2 implementation.

### Key Features:
- ✅ **Auto-Code Generation Support** - Optional code field
- ✅ **Field Normalization** - Frontend ↔ Backend mapping
- ✅ **Error Handling** - User-friendly Arabic messages
- ✅ **Validation** - Client-side validation before API calls
- ✅ **Backward Compatibility** - Supports legacy field names
- ✅ **Full CRUD Operations** - Create, Read, Update, Delete
- ✅ **Logging** - Debug logs for troubleshooting

## 📋 Field Mapping Reference

### Request Flow (Frontend → Backend)

| Frontend Form Field | Service Normalizes To | Backend DTO Field | Backend Entity |
|---------------------|----------------------|-------------------|----------------|
| `employerCode` | → `code` | `code` | `code` |
| `code` | → `code` | `code` | `code` |
| `nameAr` | → `name` | `name` | `name` (Arabic) |
| `name` | → `name` | `name` | `name` (Arabic) |
| `nameEn` | → `nameEn` | `nameEn` | `nameEn` |
| `active` | → `active` | `active` | `active` |

### Response Flow (Backend → Frontend)

| Backend Response Field | Service Maps To | Frontend Receives |
|------------------------|----------------|-------------------|
| `code` | `code` | `code` |
| `nameAr` | `nameAr` | `nameAr` |
| `nameEn` | `nameEn` | `nameEn` |
| `active` | `active` | `active` |
| `createdAt` | `createdAt` | `createdAt` |
| `updatedAt` | `updatedAt` | `updatedAt` |

## 🚀 Usage Examples

### 1️⃣ Create Employer (Auto-Generated Code)

```javascript
import { createEmployer } from 'services/api/employers.service';

// Frontend form state (no code provided)
const formData = {
  nameAr: 'شركة الواحة للتجارة',
  nameEn: 'Al Waha Trading Company',
  active: true
};

try {
  const newEmployer = await createEmployer(formData);
  
  console.log('Created employer:', newEmployer);
  // {
  //   id: 1,
  //   code: 'EMP-01',           ← Auto-generated by backend
  //   nameAr: 'شركة الواحة للتجارة',
  //   nameEn: 'Al Waha Trading Company',
  //   active: true,
  //   createdAt: '2024-12-29T10:00:00',
  //   updatedAt: '2024-12-29T10:00:00'
  // }
  
  enqueueSnackbar('تم إنشاء صاحب العمل بنجاح', { variant: 'success' });
  navigate('/employers');
} catch (error) {
  console.error('Error:', error);
  enqueueSnackbar(error.message, { variant: 'error' });
}
```

**What Happens:**
1. Service normalizes: `{ nameAr: '...' }` → `{ name: '...' }`
2. Sends to backend: `POST /api/employers` with normalized payload
3. Backend auto-generates code: `EMP-01`
4. Response normalized back: `{ name: '...' }` → `{ nameAr: '...' }`

### 2️⃣ Create Employer (Custom Code)

```javascript
import { createEmployer } from 'services/api/employers.service';

// Frontend provides custom code
const formData = {
  employerCode: 'EMP-CUSTOM-001',  // ← Custom code
  nameAr: 'شركة النور للخدمات',
  nameEn: 'Al Noor Services'
};

try {
  const newEmployer = await createEmployer(formData);
  
  console.log('Created employer with custom code:', newEmployer.code);
  // 'EMP-CUSTOM-001' ← Uses provided code
} catch (error) {
  if (error.status === 409) {
    // Code already exists
    enqueueSnackbar('رمز صاحب العمل مستخدم بالفعل', { variant: 'error' });
  }
}
```

### 3️⃣ Update Employer

```javascript
import { getEmployerById, updateEmployer } from 'services/api/employers.service';

// Step 1: Load existing employer
const employer = await getEmployerById(1);
console.log('Loaded employer:', employer);
// {
//   id: 1,
//   code: 'EMP-01',
//   nameAr: 'شركة الواحة',  ← Frontend receives nameAr
//   nameEn: 'Al Waha',
//   active: true
// }

// Step 2: User edits form
const updatedFormData = {
  employerCode: employer.code,      // Keep code
  nameAr: 'شركة الواحة المحدودة',    // Updated name
  nameEn: 'Al Waha Company Ltd',
  active: true
};

// Step 3: Submit update
try {
  const updated = await updateEmployer(employer.id, updatedFormData);
  
  console.log('Updated employer:', updated);
  enqueueSnackbar('تم تحديث صاحب العمل بنجاح', { variant: 'success' });
  navigate('/employers');
} catch (error) {
  console.error('Update failed:', error);
  enqueueSnackbar(error.message, { variant: 'error' });
}
```

## 🛡️ Error Handling Examples

### Validation Error (400)

```javascript
try {
  await createEmployer({
    nameEn: 'Al Waha Company'
    // Missing nameAr (required)
  });
} catch (error) {
  console.log('Status:', error.status);           // 400
  console.log('Message:', error.message);         // 'يرجى تصحيح الأخطاء في النموذج'
  console.log('Field Errors:', error.fieldErrors);
  // { nameAr: 'الاسم بالعربية مطلوب' }
  
  // Display field errors
  setErrors(error.fieldErrors);
}
```

---

### Duplicate Code (409)

```javascript
try {
  await createEmployer({
    employerCode: 'EMP-01',  // Already exists
    nameAr: 'شركة جديدة',

  console.log('Status:', error.status);   // 409
  console.log('Message:', error.message); // 'رمز صاحب العمل مستخدم بالفعل'
  
  enqueueSnackbar(error.message, { variant: 'error' });
}
```

## 🔍 Advanced Usage

### Manual Normalization (for custom logic)

```javascript
import { 
  normalizeEmployerRequest,
  normalizeEmployerResponse 
} from 'services/api/employers.service';

// Normalize request manually
const frontendDto = {
  employerCode: 'EMP-001',
  nameAr: 'شركة الواحة',
  nameEn: 'Al Waha'
};

const backendDto = normalizeEmployerRequest(frontendDto);
console.log(backendDto);
// {
//   code: 'EMP-001',
//   name: 'شركة الواحة',
//   nameEn: 'Al Waha',
//   active: true
// }

// Normalize response manually
const backendResponse = {
  id: 1,
  code: 'EMP-01',
  nameAr: 'شركة الواحة',
  nameEn: 'Al Waha',
  active: true,
  createdAt: '2024-12-29T10:00:00',
  updatedAt: '2024-12-29T10:00:00'
};

const frontendResponse = normalizeEmployerResponse(backendResponse);
console.log(frontendResponse);
// Same structure (backend already returns 'nameAr')
```


```
│                 Frontend Component                      │
│  (EmployerCreate.jsx, EmployerEdit.jsx, etc.)         │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
│             employers.service.js                        │
│                                                         │
│  ┌─────────────────────────────────────────────────┐  │
│  │  normalizeEmployerRequest()                     │  │
│  │  - employerCode → code                          │  │
│  │  - nameAr → name                                │  │
│  │  - Trim whitespace                              │  │
│  │  - Set defaults (active=true)                   │  │
│  └─────────────────────────────────────────────────┘  │
│                      │                                  │
│                      ▼                                  │
│  ┌─────────────────────────────────────────────────┐  │
│  │  axiosClient (HTTP Request)                     │  │
│  │  POST/GET/PUT/DELETE /api/employers             │  │
│  └─────────────────────────────────────────────────┘  │
│                      │                                  │
│                      ▼                                  │
│  ┌─────────────────────────────────────────────────┐  │
│  │  normalizeEmployerResponse()                    │  │
│  │  - Backend 'nameAr' → Frontend 'nameAr'         │  │
│  │  - Add timestamps                               │  │
│  └─────────────────────────────────────────────────┘  │
│                      │                                  │
│                      ▼                                  │
│  ┌─────────────────────────────────────────────────┐  │
│  │  handleEmployerErrors()                         │  │
│  │  - Map status codes                             │  │

│  └─────────────────────────────────────────────────┘  │
└─────────────────────┬───────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────┐
```

### Common Issues

**Issue:** Backend returns 400 "name is required"
```javascript
// Problem: Frontend sends 'nameAr' but backend expects 'name'
// ❌ Wrong:
const dto = { nameAr: 'شركة الواحة' };
await axiosClient.post('/api/employers', dto); // Direct call (bypass normalization)

// ✅ Correct:
await createEmployer({ nameAr: 'شركة الواحة' }); // Uses normalization
```

**Issue:** Code not auto-generating
```javascript
// Problem: Frontend sends empty code ''
// ❌ Wrong:
const dto = { employerCode: '', nameAr: '...' };

// ✅ Correct (omit code entirely):
const dto = { nameAr: '...' }; // Backend will auto-generate
```

**Issue:** Field errors not showing
```javascript
// Check error structure
catch (error) {
  console.log('Error object:', error);
  console.log('Field errors:', error.fieldErrors);
  
  // Should be:
  // { nameAr: 'الاسم بالعربية مطلوب' }
}
```

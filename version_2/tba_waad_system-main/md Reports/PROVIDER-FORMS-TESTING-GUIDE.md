# دليل اختبار نماذج مقدمي الخدمة والعقود
# Provider Forms Testing Guide

## 🎯 الهدف من الاختبار

التأكد من أن جميع التحسينات تعمل بشكل صحيح:
1. ✅ الكود التلقائي يظهر ويتحدث تلقائياً
2. ✅ قائمة مقدمي الخدمة تُحمّل بنجاح
3. ✅ التنقل بين الخطوات يعمل بسلاسة
4. ✅ التحقق من الصحة يعمل بشكل صحيح
5. ✅ الحفظ يتم بنجاح

## 📝 سيناريو الاختبار 1: إضافة مقدم خدمة جديد

### الخطوة 1: الوصول للصفحة
```
URL: http://localhost:3000/providers/create
```

**ما الذي يجب أن تراه:**
- [ ] عنوان الصفحة: "إضافة مقدم خدمة صحية جديد"
- [ ] Stepper في الأعلى يعرض 3 خطوات
- [ ] الخطوة الأولى مُفعّلة: "البيانات الأساسية"

### الخطوة 2: اختبار الكود التلقائي

**خطوات الاختبار:**
1. اختر نوع المقدم: "مستشفى"
2. **توقف! لاحظ الكود التلقائي** - يجب أن يتحدث إلى: `HOS-XX-####`

**ما الذي يجب أن تراه:**
```
┌─────────────────────────────────────────────┐
│ ℹ️ الرمز التلقائي: سيتم إنشاء رمز تلقائي   │
│    لمقدم الخدمة عند الحفظ                  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ [AUTO] الرمز التلقائي                      │
│        HOS-XX-4321                          │ ← يجب أن يظهر هنا
│        سيتم توليد الرمز تلقائياً...        │
└─────────────────────────────────────────────┘
```

3. أدخل الاسم بالعربية: "مستشفى السلام"
4. **لاحظ الكود مرة أخرى** - يجب أن يتحدث إلى: `HOS-مس-####`

**النتيجة المتوقعة:**
```
HOS-مس-4321  (أو رقم مختلف في النهاية)
│   │  │
│   │  └─ Timestamp (4 أرقام فريدة)
│   └──── الأحرف الأولى من "مستشفى السلام" = مس
└────────── نوع المقدم HOSPITAL = HOS
```

### الخطوة 3: إكمال البيانات الأساسية

**املأ الحقول التالية:**
```
الاسم بالعربية:      مستشفى السلام
الاسم بالإنجليزية:    Al-Salam Hospital
نوع مقدم الخدمة:      مستشفى 🏥
رقم الترخيص:          LIC-2026-001
الرقم الضريبي:        TAX-123456 (اختياري)
```

**اختبار التحقق من الصحة:**
- [ ] حاول الضغط على "التالي" بدون تعبئة الحقول
- [ ] **يجب أن يظهر:** رسالة خطأ "يرجى تعبئة جميع الحقول المطلوبة"
- [ ] **يجب أن تُبرز:** الحقول الفارغة باللون الأحمر

**بعد التعبئة الصحيحة:**
- [ ] اضغط "التالي"
- [ ] **يجب أن ينتقل:** إلى الخطوة 2 "الموقع والتواصل"

### الخطوة 4: الموقع والتواصل

**املأ الحقول:**
```
المدينة:              الرياض
العنوان:              شارع الملك فهد
رقم الهاتف:           0112345678
البريد الإلكتروني:    info@alsalam.sa
```

**اختبار التحقق من البريد:**
- [ ] أدخل بريد خاطئ: `invalid-email`
- [ ] **يجب أن يظهر:** "البريد الإلكتروني غير صحيح"
- [ ] صحح البريد: `info@alsalam.sa`
- [ ] **يجب أن يختفي:** رسالة الخطأ

**معلومات العقد الأولية (اختياري):**
```
⚠️ يمكنك تخطي هذا القسم - سيظهر تنبيه:
"يمكنك إضافة معلومات العقد لاحقاً من خلال صفحة العقود"
```

**التنقل:**
- [ ] اضغط "السابق" - يجب العودة للخطوة 1
- [ ] **تحقق:** البيانات محفوظة
- [ ] ارجع للخطوة 2 واضغط "التالي"

### الخطوة 5: المراجعة

**ما الذي يجب أن تراه:**
```
═══════════════════════════════════════
         مراجعة البيانات
───────────────────────────────────────

البيانات الأساسية
─────────────────
الرمز التلقائي:      HOS-مس-4321
نوع المزود:           مستشفى
الاسم بالعربية:       مستشفى السلام
الاسم بالإنجليزية:    Al-Salam Hospital
رقم الترخيص:          LIC-2026-001
الرقم الضريبي:        TAX-123456

الموقع والتواصل
───────────────
المدينة:              الرياض
العنوان:              شارع الملك فهد
الهاتف:               0112345678
البريد الإلكتروني:    info@alsalam.sa
═══════════════════════════════════════
```

**الإجراءات:**
- [ ] راجع جميع البيانات
- [ ] إذا وجدت خطأ، اضغط "السابق" وصحح
- [ ] إذا كانت البيانات صحيحة، اضغط "حفظ مقدم الخدمة"

### الخطوة 6: الحفظ

**عند الضغط على "حفظ":**
- [ ] **يجب أن يظهر:** النص يتغير إلى "جاري الحفظ..."
- [ ] **يجب أن يُعطّل:** جميع الأزرار
- [ ] **بعد ثوانٍ:** رسالة خضراء "تم إنشاء مقدم الخدمة بنجاح" ✅
- [ ] **التوجيه:** العودة لصفحة قائمة المقدمين `/providers`

**في حالة الخطأ:**
- [ ] **يجب أن يظهر:** رسالة حمراء توضح السبب ❌
- [ ] **يبقى المستخدم:** في نفس الصفحة لتصحيح الخطأ

## 📝 سيناريو الاختبار 2: إضافة عقد جديد

### الخطوة 1: الوصول للصفحة
```
URL: http://localhost:3000/provider-contracts/create
```

**ما الذي يجب أن تراه:**
- [ ] عنوان الصفحة: "إنشاء عقد مقدم خدمة جديد"
- [ ] 3 أقسام رئيسية:
  - 🏥 اختيار مقدم الخدمة
  - 📅 تفاصيل العقد
  - 💰 نموذج التسعير

### الخطوة 2: حالات تحميل قائمة المقدمين

**السيناريو أ: التحميل الناجح**
```
1. عند فتح الصفحة:
   ┌─────────────────────────────────────────┐
   │ ℹ️ [🔄] جاري تحميل قائمة مقدمي الخدمة... │
   └─────────────────────────────────────────┘

2. بعد التحميل (1-2 ثانية):
   ┌─────────────────────────────────────────┐
   │ مقدم الخدمة *                           │
   │ [ابحث واختر مقدم الخدمة الصحية]        │ ← قابل للاستخدام
   └─────────────────────────────────────────┘
```

**السيناريو ب: فشل التحميل**
```
┌─────────────────────────────────────────────────┐
│ ❌ فشل تحميل قائمة مقدمي الخدمة.              │
│    يرجى المحاولة مرة أخرى.                    │
│                          [إعادة المحاولة] ←   │
└─────────────────────────────────────────────────┘
```
- [ ] اضغط "إعادة المحاولة"
- [ ] **يجب:** إعادة محاولة التحميل

**السيناريو ج: القائمة فارغة**
```
┌─────────────────────────────────────────────────┐
│ ⚠️ لا توجد مقدمي خدمة متاحين.                 │
│    يرجى إضافة مقدم خدمة أولاً من              │
│    [صفحة مقدمي الخدمات] ←                    │
└─────────────────────────────────────────────────┘
```
- [ ] اضغط الرابط
- [ ] **يجب:** التوجيه إلى `/providers/create`

### الخطوة 3: اختيار مقدم الخدمة

**خطوات الاختبار:**
1. اضغط على حقل "مقدم الخدمة"
2. **يجب أن تظهر:** قائمة منسدلة بجميع المقدمين

**تنسيق عناصر القائمة:**
```
┌─────────────────────────────────────────┐
│ مستشفى السلام                          │ ← الاسم بالعربي
│ Al-Salam Hospital  [الرياض]            │ ← الاسم بالإنجليزي + المدينة
├─────────────────────────────────────────┤
│ عيادة النور                            │
│ Al-Noor Clinic  [جدة]                  │
├─────────────────────────────────────────┤
│ صيدلية الشفاء                          │
│ Al-Shifa Pharmacy  [الدمام]            │
└─────────────────────────────────────────┘
```

3. **اختبر البحث:**
   - اكتب: "سلام"
   - **يجب أن تُرشّح:** "مستشفى السلام" فقط

4. اختر "مستشفى السلام"

### الخطوة 4: اختبار الكود التلقائي للعقد

**بعد اختيار المقدم مباشرة:**
```
┌─────────────────────────────────────────────┐
│ ℹ️ رمز العقد: سيتم إنشاء رمز تلقائي للعقد  │
│    عند الحفظ                               │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ [AUTO] رمز العقد                           │
│        PC-مس-202601-456                    │ ← تم التوليد تلقائياً
│        سيتم توليد الرمز تلقائياً بناءً... │
└─────────────────────────────────────────────┘
```

**تحليل الكود:**
```
PC-مس-202601-456
│  │  │      │
│  │  │      └─ Timestamp فريد
│  │  └──────── سنة+شهر (YYYYMM)
│  └─────────── الأحرف الأولى من اسم المقدم
└────────────── Provider Contract
```

**اختبر التحديث:**
- [ ] غيّر تاريخ البداية إلى شهر آخر
- [ ] **يجب:** تحديث الكود (مثلاً `202601` → `202602`)

### الخطوة 5: تفاصيل العقد

**املأ الحقول:**
```
تاريخ بداية العقد:    01/01/2026
تاريخ انتهاء العقد:   01/01/2027
```

**مباشرة بعد تعيين التواريخ:**
```
┌─────────────────────────────────────────────┐
│ ✅ مدة العقد: 12 شهر (1 سنة و 0 شهر)       │
└─────────────────────────────────────────────┘
```

**اختبر الحساب:**
| تاريخ البداية | تاريخ النهاية | النتيجة المتوقعة |
|---------------|---------------|------------------|
| 01/01/2026 | 01/01/2027 | 12 شهر (1 سنة و 0 شهر) |
| 01/01/2026 | 01/07/2027 | 18 شهر (1 سنة و 6 شهر) |
| 01/01/2026 | 01/01/2028 | 24 شهر (2 سنة و 0 شهر) |

**اختبر التحقق:**
- [ ] اجعل تاريخ النهاية قبل تاريخ البداية
- [ ] **يجب:** رسالة خطأ "تاريخ النهاية يجب أن يكون بعد تاريخ البداية"

### الخطوة 6: نموذج التسعير

**اختبر كل نموذج:**

**1. نسبة خصم 💰**
```
اختر: نسبة خصم
     ↓
┌─────────────────────────────────────────┐
│ نموذج التسعير *     نسبة الخصم % *     │
│ [نسبة خصم 💰]       [10.0]              │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ℹ️ خصم نسبة مئوية من السعر الأصلي       │
└─────────────────────────────────────────┘
```

**اختبر التحقق:**
- [ ] أدخل: `-5` → **خطأ:** "نسبة الخصم يجب أن تكون بين 0 و 100"
- [ ] أدخل: `150` → **خطأ:** "نسبة الخصم يجب أن تكون بين 0 و 100"
- [ ] أدخل: `10.5` → **صحيح** ✅

**2. سعر ثابت 📌**
```
اختر: سعر ثابت
     ↓
حقل نسبة الخصم يختفي ❌
فقط: [نموذج التسعير: سعر ثابت]
```

**3. تسعير متدرج 📊**
```
اختر: تسعير متدرج
     ↓
"أسعار متدرجة حسب الكمية"
```

**4. سعر تفاوضي 🤝**
```
اختر: سعر تفاوضي
     ↓
"أسعار حسب الاتفاق المسبق"
```

## 🐛 الأخطاء الشائعة وحلولها

### خطأ: الكود التلقائي لا يتحدث
**السبب المحتمل:**
- لم تختر نوع المقدم
- لم تدخل الاسم بالعربية

**الحل:**
1. تأكد من اختيار نوع المقدم
2. أدخل اسم بالعربية
3. انتظر ثانية - التحديث يحدث في الوقت الفعلي

### خطأ: قائمة المقدمين فارغة
**السبب المحتمل:**
- لا يوجد مقدمي خدمة في النظام
- خطأ في الشبكة
- خطأ في الـ API

**الحل:**
1. افتح Console (F12) وتحقق من الأخطاء
2. تحقق من Network tab - هل API استُدعي؟
3. جرّب زر "إعادة المحاولة"
4. أضف مقدم خدمة من الصفحة المخصصة

### خطأ: لا يمكن الانتقال للخطوة التالية
**السبب المحتمل:**
- حقول مطلوبة غير معبأة
- بيانات غير صحيحة

**الحل:**
1. تحقق من جميع الحقول ذات العلامة *
2. ابحث عن رسائل الخطأ باللون الأحمر
3. صحح البيانات وحاول مرة أخرى

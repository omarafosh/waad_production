## 📊 نقاط النهاية المستخدمة

### 1. POST /api/admin/users
**الغرض:** إنشاء مستخدم جديد  
**Payload:**
```json
{
  "username": "string (3-50 أحرف)",
  "password": "string (8+ أحرف، سياسة مُفرضة)",
  "fullName": "string (مطلوب)",
  "email": "string (بريد إلكتروني صالح، فريد)",
  "phone": "string (اختياري)",
  "employerId": "number (مشروط - إذا كان دور EMPLOYER_ADMIN)"
}
```

### 2. POST /api/admin/users/{userId}/assign-roles
**الغرض:** تعيين أدوار للمستخدم  
**Payload:**
```json
{
  "roleIds": [1, 2, 3]
}
```

### 3. POST /api/admin/users/{userId}/remove-roles
**الغرض:** إزالة أدوار من المستخدم  
**Payload:**
```json
{
  "roleIds": [4, 5]
}
```

### 4. PUT /api/admin/users/{id}
**الغرض:** تحديث معلومات المستخدم الأساسية  
**Payload:**
```json
{
  "fullName": "string",
  "email": "string",
  "phone": "string",
  "active": "boolean"
}
```
**ملاحظة:** لا username، لا password، لا roles
